## 2. Learn the basics everyone needs

1. **Sign in and secure your account.** [Manual 01](manuals/01-getting-started-and-mfa.md) covers sign-in, mandatory MFA, passkeys and idle timeouts.
2. **Learn the words.** The [Glossary](GLOSSARY.md) explains terms such as `SOAP`, `5Ps`, `LOA`, `C-SSRS` and `k`-anonymity.
3. **See the screens.** The [Visual Guide](VISUAL_GUIDE.md) arranges every synthetic screenshot by task.

## 3. How the documents are organised

| Folder | Kind of document | Use it when you want to… |
| :--- | :--- | :--- |
| `decks/` | Explanation | Understand the platform and why it is built this way |
| `manuals/` | Reference | Look up how a module works |
| `personas/` | How-to guides | Follow a role's day-to-day tasks |
| `training/` | Tutorials | Practise hands-on in a synthetic training tenant |
| `GLOSSARY.md`, `INDEX.md` | Reference | Find a term or a route |

## 4. Ground rules

- Use **synthetic data only** in any training or demo tenant.
- Your clinic's own standard operating procedures take precedence over this showcase knowledge base.
- Found a problem with the docs? See [CONTRIBUTING.md](CONTRIBUTING.md). Found a security issue? See [SECURITY.md](SECURITY.md).
